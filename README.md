## 一、这份作品集是什么

这是我在南昌大学本课程学习期间，**逐周积累**的个人作品集仓库。

每一周我都会把当周的**代码、实验记录、实验报告**整理进对应文件夹，一学期下来，
这里就自动形成了一份能证明「我做过什么、怎么想的、踩过哪些坑」的完整成长档案。

## 五、每周怎么提交

```bash
# 1. 进入本周文件夹，写代码、写报告
# 2. 把改动加入「待提交清单」
git add .

# 3. 拍一张快照（Commit），说明这周做了什么
git commit -m "feat(week03): 完成第 3 周实验与报告"

# 4. 推送到 GitHub
git push
```
